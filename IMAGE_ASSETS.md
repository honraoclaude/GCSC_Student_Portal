## GENERATION GUIDELINES

### AI Image Generation Best Practices

#### Tool Recommendations
- **Primary**: Midjourney (best for quality, consistency)
- **Alternative**: DALL-E 3 (good for specific requests)
- **Fallback**: Stable Diffusion (faster, cost-effective)

#### Quality Standards

**All images must meet:**
- Minimum 4K resolution (4000x2000+) for high-quality scaling
- Professional SaaS/educational aesthetic (never cartoony or childish)
- Authentic diverse representation (multiple ethnicities, ages, abilities)
- Clean, modern design (avoid clutter, unnecessary detail)
- Cohesive color palette aligned with brand
- Text-free (except for UI mockups where text is part of design)
- No watermarks or AI generation artifacts
- Properly licensed or generated with commercial rights

#### Prompt Engineering Tips

1. **Lead with Context**: Start with purpose and placement
   - "For a landing page hero background" ← Sets expectation
   
2. **Specific Visual Details**: Be precise about what's visible
   - "Math equations, graphs, coordinate systems" ← Concrete elements
   
3. **Diversity & Inclusion**: Always specify diverse representation
   - "Mix of ethnicities, genders" ← Non-negotiable
   
4. **Style Direction**: Mention inspiration/aesthetic
   - "Modern SaaS illustration, Apple Education aesthetic" ← Style reference
   
5. **Color Guidance**: Specify brand colors explicitly
   - "Blues (#0066FF), purples (#7C3AED), gold accents" ← Exact colors
   
6. **Mood & Tone**: Communicate the feeling
   - "Encouraging, motivating, warm" ← Emotional direction
   
7. **Technical Requirements**: Include dimensions and format
   - "1920x1080 for desktop, 1080x1080 for mobile" ← Multiple sizes needed
   
8. **Negations**: State what NOT to include
   - "No humanoid AI, NOT cartoony, no watermarks" ← Clear exclusions

#### Post-Generation Processing

1. **Upscaling**: Use AI upscaler (4x preferred) for print quality
2. **Color Correction**: Ensure brand colors match exactly
3. **Cropping**: Generate slightly oversized, then crop to exact dimensions
4. **Format Optimization**: Export as high-quality PNG with transparency where needed
5. **Accessibility Check**: Verify contrast, color-blindness compatibility
6. **Consistency Review**: Compare against brand system and existing assets

## ANIMATION RECOMMENDATIONS

### Image-Based Animations

#### 1. Hero Image Parallax (Landing Page)
```css
/* Subtle parallax effect on hero image */
@media (prefers-reduced-motion: no-preference) {
  .hero-image {
    animation: parallax 20s ease-in-out infinite;
  }
  
  @keyframes parallax {
    0%, 100% { transform: translateY(0px); }
    50% { transform: translateY(-10px); }
  }
}
```

#### 2. Achievement Badge Unlock
```css
/* Celebration animation for achievement badges */
.achievement-unlock {
  animation: zoomIn 0.5s ease-out,
            bounce 0.6s ease-out 0.5s,
            glow 2s ease-in-out 1.1s infinite;
}

@keyframes zoomIn {
  from { transform: scale(0); opacity: 0; }
  to { transform: scale(1); opacity: 1; }
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}

@keyframes glow {
  0%, 100% { filter: drop-shadow(0 0 0 rgba(255,215,0,0)); }
  50% { filter: drop-shadow(0 0 15px rgba(255,215,0,0.6)); }
}
```

#### 3. Empty State Floating Animation
```css
/* Gentle floating motion for empty state illustrations */
.empty-state-illustration {
  animation: float 3s ease-in-out infinite;
}

@keyframes float {
  0%, 100% { transform: translateY(0px); }
  50% { transform: translateY(-15px); }
}
```

#### 4. Progress Bar Fill Animation
```css
/* Smooth fill animation for XP/progress bars */
.progress-bar-fill {
  transition: width 0.6s cubic-bezier(0.34, 1.56, 0.64, 1);
}

/* Glow pulse on milestone completion */
.progress-milestone-hit {
  animation: glowPulse 0.8s ease-out;
}

@keyframes glowPulse {
  0% { box-shadow: 0 0 20px rgba(16,185,129,0.8); }
  100% { box-shadow: 0 0 0 rgba(16,185,129,0); }
}
```

#### 5. Loading Spinner Continuous Rotation
```css
/* Geometric spinner rotation */
.loading-spinner {
  animation: spin 2s linear infinite;
}

@keyframes spin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

/* Respect reduced motion */
@media (prefers-reduced-motion: reduce) {
  .loading-spinner {
    animation: none;
    opacity: 0.5;
  }
}
```

#### 6. Confetti Effect (Canvas-Based)
For celebration animations like achievement unlocks and level-ups, use canvas-based confetti library:

```javascript

    particleCount: 100,
```

